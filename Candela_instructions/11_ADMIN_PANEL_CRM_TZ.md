# Техническое задание: Frontend Административная панель (Candela Control Hub)

**Проект:** Candela Home — Экосистема премиальной домашней парфюмерии (свечи, диффузоры, саше).  
**Назначение документа:** Полная спецификация для фронтенд-разработчика для создания изолированного SPA-приложения администратора (Admin Web / Telegram Mini App CRM).  
**Версия документа:** 1.0.0  
**Целевые платформы:** Telegram Mini App (iOS / Android / Desktop) + Отдельный браузерный веб-интерфейс (PWA / Web SPA).

---

## 1. Концепция и ключевые требования

### 1.1. Назначение системы
Изолированная панель управления магазином **Candela Control Hub**, предназначенная для:
1. Мониторинга финансовых показателей (выручка, средний чек, чистая прибыль).
2. Оперативной обработки и логистики клиентских заказов (смена статусов, передача трек-номеров СДЭК/Почты).
3. Управления номенклатурой товаров, ароматическими пирамидами и складскими остатками (Stock Alert).
4. Настройки промокодов, акций и маркетинговых бейджей.
5. Модерации и публикации официальных ответов на отзывы покупателей.
6. Разграничения прав сотрудников на базе ролевой модели (RBAC).

### 1.2. Адаптивность и форматы использования
Интерфейс обязан одинаково безупречно работать в двух режимах:
* **Mobile / TMA Mode (до 430px):** Компактный эргономичный вид внутри Telegram на смартфоне (управление в 1–2 тапа, нижний навигационный таб-бар, поддержка свайпов, тактильный отклик Haptic Feedback).
* **Desktop / Tablet Mode (от 768px до 1920px):** Полноценная CRM-панель для монитора ноутбука или Telegram Desktop (боковой сворачиваемый сайдбар, расширенные таблицы данных с сортировкой, фильтрацией, пагинацией и экспортом в CSV/XLSX, многоколоночные формы).

### 1.3. Стек технологий (Рекомендуемый для фронтенда)
* **Фреймворк:** React 18+ / Vite, TypeScript (строгая типизация).
* **Стилизация:** Tailwind CSS (с поддержкой тёмной и светлой темы).
* **Компонентная база / UI:** Radix UI / Shadcn UI / Lucide React Icons.
* **Стейт-менеджмент:** TanStack Query (React Query) v5 — для кэширования API и мгновенного обновления без лишних перезагрузок + Zustand (для UI-состояний).
* **Графика и чарты:** Recharts / Chart.js.
* **Telegram интеграция:** `@telegram-apps/sdk-react` (или `window.Telegram.WebApp`).

## 3. Ролевая модель доступа (RBAC)

Приложение должно скрывать или блокировать элементы интерфейса в зависимости от роли текущего пользователя:

| Роль | Доступ к разделам | Разрешенные действия |
| :--- | :--- | :--- |
| **👑 Владелец (Owner)** | Все разделы (100%) | Полный доступ: финансовая аналитика, удаление товаров, изменение ролей, скидки, выгрузка базы. |
| **💼 Управляющий (Admin)** | Заказы, Каталог, Склад, Скидки, Отзывы | Управление товарами и ценами, смена статусов, ответы на отзывы. Без права удаления магазина и изменения роли Владельца. |
| **📦 Сборщик / Логист (Manager)** | Только «Заказы» и «Склад» (read/write остатков) | Просмотр состава посылок, печать накладных, смена статусов сборки, ввод трек-номеров СДЭК. Закрыты финансы, себестоимость и редактирование товаров. |
| **✍️ Контент-менеджер (Editor)** | «Каталог» и «Отзывы» | Добавление фото, редактирование текстов пирамид и ответов на отзывы. Без доступа к финансам и заказам. |

## 4. Архитектура экранов и детальный функционал

### 4.1. Навигация приложения
* **Desktop:** Левый закрепленный сайдбар (Логотип Candela Admin, пункты: `Дашборд`, `Заказы`, `Каталог`, `Склад`, `Маркетинг/Скидки`, `Отзывы`, `Сотрудники/Роли`, переключатель темы, аватар и кнопка выхода).
* **Mobile:** Верхний компактный бар (логотип + индикатор роли) + Нижний таб-бар с 4–5 основными иконками и кнопка `Еще` (шторка с остальными разделами).

---

### 4.2. Экран 1: 📊 Дашборд и Аналитика (Только Owner / Admin)
Центр контроля ключевых метрик бизнеса в реальном времени.

1. **Фильтр периода:** Кнопки быстрого выбора: `Сегодня`, `Вчера`, `7 дней`, `Месяц`, `Квартал`, `Произвольный диапазон дат`.
2. **KPI-карточки (Метрики):**
   * **Выручка (₽):** Сумма всех оплаченных заказов за период + процент прироста к прошлому периоду.
   * **Чистая прибыль (₽):** Выручка минус себестоимость сырья и логистики (опциональное поле себестоимости в товаре).
   * **Количество заказов (шт.):** Всего заказов + средний чек (AOV).
   * **Активные заказы в работе:** Счетчик заказов, требующих внимания (Оплачены, но не отправлены).
3. **Интерактивные графики (Recharts):**
   * **Динамика продаж:** Линейный график или Bar Chart (выручка по дням/часам).
   * **Структура продаж:** Круговая диаграмма (Свечи / Диффузоры / Саше / Подарочные наборы).
4. **Топ ароматов-бестселлеров:** Таблица топ-5 позиций по количеству проданных штук и общей выручке.

---

### 4.3. Экран 2: 📦 Управление заказами (Order Management System)
Главный рабочий экран для ежедневной операционки.

1. **Режимы отображения:**
   * **Таблица (Desktop):** Колонки: Номер заказа (`#CH-1048`), Дата/время, Клиент (Имя, Телефон, Telegram @username), Состав (кратко), Сумма, Доставка (СДЭК ПВЗ / Курьер / Почта), Статус заказа, Действие.
   * **Kanban-доска (Desktop / Tablet):** Колонки по статусам:
     1. `Новые (Оплачены)`
     2. `В сборке`
     3. `Переданы в доставку`
     4. `Доставлены`
     5. `Отменены / Возврат`
   * **Карточки заказов (Mobile):** Быстрый компактный список с цветными бейджами статусов.
2. **Фильтры и быстрый поиск:**
   * Живой поиск по номеру заказа (`CH-1025`), имени покупателя, телефону или трек-номеру.
   * Быстрые табы по статусам заказа.
3. **Детальная модалка / Drawer заказа:**
   * Полный состав позиций: фото товара, выбранный объем (100/250 мл), тип фитиля (деревянный/хлопковый), количество, цена.
   * Блок оплаты: платежный шлюз (ЮKassa), ID транзакции, ссылка на фискальный чек 54-ФЗ.
   * Блок доставки: служба (СДЭК/Почта), адрес ПВЗ, ФИО получателя, телефон.
   * **Поле ввода трек-номера:** При вводе трека (например, накладная СДЭК `1456789012`) и нажатии «Сохранить и уведомить»:
     * Статус заказа автоматически переводится в `SHIPPED` (В пути).
     * Клиенту в Telegram-бот улетает моментальное сообщение с треком и ссылкой на отслеживание.
   * Кнопка «Печать товарного чека / Комплектовочного листа» (PDF/Print view).

---

### 4.4. Экран 3: 🕯️ Каталог товаров (Product Management)
Управление номенклатурой витрины.

1. **Список товаров:**
   * Карточка/строка: Главное фото, Наименование, Категория, Базовая цена, Текущий остаток (сумма по всем объемам), Статус видимости (Active / Draft / Hidden).
   * Быстрый переключатель видимости (Toggle On/Off): моментально скрывает товар с витрины клиентского Mini App, если он временно недоступен.
2. **Форма добавления / редактирования товара:**
   * **Основное:** Название, Slug (ЧПУ), Категория (Свечи, Диффузоры, Саше, Наборы), Подзаголовок (эмоциональное описание).
   * **Медиа-галерея:** Drag-and-drop загрузка фотографий (до 5 шт), изменение порядка картинок, назначение главной обложки.
   * **Ольфакторная пирамида:**
     * Верхние ноты (чипсы/теги: *Бергамот, Розовый перец*).
     * Ноты сердца (*Табачный лист, Мед, Какао*).
     * Базовые ноты (*Ваниль, Бобы тонка, Амбра*).
   * **Вариации объемов и цен:**
     * Таблица: Название объема (*100 мл, 250 мл*), Дельта цены (+650 ₽ к базе), Время горения/действия (*до 45 часов*), Начальный остаток (шт.), Себестоимость (₽).
   * **Опции товара:** Чекбоксы: «Деревянный фитиль», «Хлопковый фитиль».
   * **Маркетинговые бейджи:** Выбор бейджа (*«Хит сезона»*, *«Масла из Граса»*, *«Лимитированный тираж»*, *«New»*).

---

### 4.5. Экран 4: 📦 Контроль остатков и Склад (Stock Inventory)
Предотвращение дефицита и овербукинга.

1. **Матрица складских остатков:**
   * Таблица с группировкой по товарам и их модификациям (например: *Свеча «Табак-Ваниль» 100 мл — 14 шт., 250 мл — 2 шт.*).
   * Быстрое прямое редактирование остатка прямо в таблице (Inline Edit: нажал, ввел новое число, нажал Enter).
2. **Система критических алертов (Low Stock Alert):**
   * Настройка порога критического остатка (например, `< 5 шт.`).
   * Цветовая индикация:
     * 🟢 Зеленый: Достаточно (> 10 шт).
     * 🟡 Желтый: Мало (5–10 шт).
     * 🔴 Красный: Критично (< 5 шт) или Закончился (0 шт).
3. **Журнал движения товара:** История списаний (заказ `#CH-1025` списал 1 шт.) и ручных оприходований администратором.

---

### 4.6. Экран 5: 🏷️ Маркетинг, Промокоды и Скидки
Инструменты для увеличения среднего чека и повторных продаж.

1. **Создание и список промокодов:**
   * Код промокода (например: `CANDELAVIP`, `SPRING20`).
   * Тип скидки: Процентная (например, `15%`) или Фиксированная сумма (например, `500 ₽`).
   * Условия применения:
     * Минимальная сумма заказа (например: *«Действует при заказе от 3 000 ₽»*).
     * Лимит использования (например: *«Первые 50 активаций»* или *«1 раз на одного пользователя»*).
     * Срок действия (Дата начала и дата окончания).
   * Счетчик активаций (активирован 28 из 50 раз).
   * Статус: Активен / Приостановлен / Истек.
2. **Управление баннером главной страницы:**
   * Загрузка баннера для Hero-секции витрины.
   * Текст заголовка и подзаголовка специального предложения.

---

### 4.7. Экран 6: ⭐ Отзывы и Репутация (Reviews Management)
Работа с обратной связью покупателей.

1. **Лента отзывов:**
   * Карточка отзыва: Дата, Автор (@username), Товар, Оценка звездами (1–5), Бейдж *«✓ Проверенная покупка»*, Выбранные критерии (*Соответствует описанию: Да, Стойкость: Стойкий*), Плюсы, Минусы, Текст, Прикрепленные фото.
2. **Действия администратора:**
   * **[ Ответить от лица Candela Home ]:** Поле ввода ответа. После отправки ответ мгновенно отображается под отзывом в клиентском приложении с золотым бейджем бренда.
   * **[ Скрыть / Опубликовать ]:** Снятие с публикации в случае спама или нецензурной лексики.

---

### 4.8. Экран 7: 👥 Управление сотрудниками (Только Owner)
1. **Список сотрудников:**
   * Telegram ID, Имя/Никнейм, Назначенная роль (`Admin`, `Manager`, `Editor`), Дата добавления.
2. **Добавление нового сотрудника:**
   * Ввод Telegram ID или пересылка контакта.
   * Выбор роли из выпадающего списка.
   * Кнопка «Отозвать доступ» (мгновенное удаление сессии).

## 6. Контракты REST API (Бэкенд-взаимодействие)

Все запросы к админскому API обязаны передавать заголовок авторизации:
`Authorization: Bearer <ADMIN_JWT_TOKEN>` (или валидированный заголовок Telegram `X-Telegram-Init-Data`).

### 6.1. Авторизация
* `POST /api/v1/admin/auth/telegram` — Верификация `initData` Telegram, проверка вхождения в белый список администраторов, выдача сессионного JWT-токена с правами роли.
* `GET /api/v1/admin/auth/me` — Получение профиля текущего админа и списка его разрешений.

### 6.2. Аналитика
* `GET /api/v1/admin/analytics/dashboard?period=7d` — Получение агрегированных данных KPI и графиков за период (`today`, `yesterday`, `7d`, `30d`, `custom&from=...&to=...`).

### 6.3. Заказы
* `GET /api/v1/admin/orders?status=PAID&page=1&limit=20&search=...` — Постраничный список заказов с фильтрами.
* `GET /api/v1/admin/orders/{id}` — Детали заказа.
* `PATCH /api/v1/admin/orders/{id}/status` — Смена статуса заказа (`{ "status": "PACKING" }`).
* `POST /api/v1/admin/orders/{id}/tracking` — Привязка трек-номера (`{ "trackingNumber": "1456789012", "notifyUser": true }`).

### 6.4. Каталог и Склад
* `GET /api/v1/admin/products` — Полный список товаров (включая скрытые).
* `POST /api/v1/admin/products` — Создание нового товара.
* `PUT /api/v1/admin/products/{id}` — Полное обновление данных товара.
* `PATCH /api/v1/admin/products/{id}/status` — Быстрое переключение видимости (`{ "isActive": false }`).
* `DELETE /api/v1/admin/products/{id}` — Удаление товара (только Owner).
* `POST /api/v1/admin/media/upload` — Загрузка изображений (Multipart form-data ➔ S3/Хранилище ➔ возвращает CDN URL).
* `PATCH /api/v1/admin/inventory/quick-update` — Быстрое обновление остатков со склада (`{ "variationId": "...", "newStock": 15 }`).

### 6.5. Промокоды
* `GET /api/v1/admin/promos` — Список промокодов.
* `POST /api/v1/admin/promos` — Создание промокода.
* `PATCH /api/v1/admin/promos/{id}/toggle` — Активация/деактивация промокода.

### 6.6. Отзывы
* `GET /api/v1/admin/reviews` — Список всех отзывов.
* `POST /api/v1/admin/reviews/{id}/reply` — Публикация ответа компании (`{ "replyText": "Спасибо за теплые слова..." }`).
* `PATCH /api/v1/admin/reviews/{id}/visibility` — Скрытие/отображение отзыва.

## 7. Чек-лист приемки фронтенда (Quality Assurance)

1. [ ] **Безопасность:** Интерфейс не отображает конфиденциальные экраны (выручка, сотрудники), если у пользователя нет роли `OWNER` или `ADMIN`.
2. [ ] **Эргономика TMA:** На смартфоне внутри Telegram интерфейс не имеет горизонтального скролла, клавиатура не перекрывает активные инпуты, работает тактильный отклик (Haptic Feedback) на ключевых кнопках.
3. [ ] **Скорость работы:** Таблицы заказов и каталога имеют скелетон-загрузчики (Skeleton UI) и мгновенный оптимистичный UI при смене статусов (Optimistic Updates).
4. [ ] **Валидация:** Все формы (добавление товара, промокод, ввод трек-номера) валидируются на клиенте с понятными текстами ошибок.
5. [ ] **Темы:** Поддержка 100% контрастности и читаемости как в светлой, так и в тёмной теме Telegram.
